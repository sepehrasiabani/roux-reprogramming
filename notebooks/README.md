# Notebooks

Analysis notebooks, one per pipeline stage. Each loads data, calls the
`roux_reprogramming` package, and displays results.

- `01_preprocessing.ipynb` — QC, normalisation, feature selection
- `02_clustering_annotation.ipynb` — clustering and marker-gene annotation
- `03_grn_construction.ipynb` — GRN inference
- `04_perturbation_validation.ipynb` — simulation and predicted-vs-measured validation
- `05_aging_axis_scoring.ipynb` — ageing axis and rejuvenation scoring
- `06_robustness.ipynb` — disentangling and combination classifier
